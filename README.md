# Hercal — protótipo da home

Home responsiva em HTML, CSS e JavaScript, com identidade e fotos fornecidas pela Hercal e história integral de Danielle Caldeira Magalhães.

## Publicar no GitHub Pages

1. Extraia este ZIP.
2. Crie um repositório no GitHub.
3. Envie o conteúdo extraído para a raiz do repositório, mantendo `index.html`, os arquivos CSS e `script.js` junto da pasta `assets`. Envie os arquivos extraídos, não o ZIP.
4. Nas configurações do repositório, habilite GitHub Pages usando a branch que contém os arquivos e a pasta raiz.

Não precisa instalar dependências ou executar build. Os caminhos são relativos e funcionam em páginas de projeto.

## Editar

- `index.html`: textos, fotos e estrutura.
- `styles.css`: layout base.
- `brand.css`: cores, fontes e identidade visual.
- `story.css`: história da Dani e novas seções de fotos.
- `script.js`: menu mobile, seleção de segmentos e privacidade.
- `assets/`: fotos, logomarca, grafismos e fontes com licenças.

Para abrir localmente, use `index.html` no navegador.

## Estado da apresentação

Esta é uma versão para avaliação. Missão, visão, certificações e outros conteúdos sinalizados precisam de validação. A abertura utiliza foto; o vídeo institucional ainda não foi incorporado.

O arquivo `robots.txt` e a marcação `noindex` pedem que buscadores não indexem a prévia. Eles não restringem o acesso: uma publicação pública pode ser acessada por qualquer pessoa com a URL.

Fotos, textos, logomarca e grafismos são materiais da Hercal e não recebem licença de redistribuição aberta por estarem neste repositório. As fontes têm suas próprias licenças OFL em `assets/fonts/`.
